# 🌐 Bookmarks Project

A simple and organized bookmarks webpage built using **HTML5 and CSS3**. This project provides quick access to frequently used websites through a clean and user-friendly interface.

## ✨ Features

- Organized primary and secondary bookmarks
- Quick access to popular websites
- Clean and professional user interface
- Simple, responsive layout
- External links open in a new tab
- Hover effects for better user experience

## 🔗 Bookmarked Websites

### Primary Bookmarks
- [Google](https://www.google.com)
- [YouTube](https://www.youtube.com)
- [Yahoo](https://www.yahoo.com)
- [Facebook](https://www.facebook.com)
- [Corvit](https://www.corvit.com)

### Secondary Bookmarks
- [CapCut](https://www.capcut.com)
- [Instagram](https://www.instagram.com)

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click any bookmark to visit the website.
